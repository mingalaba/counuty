# Sitio Web Counity V1

## Objetivo

Crear la primera versión del sitio web de Counity que cumpla tres funciones simultáneas:

1. **Explicar** qué es Counity y cómo funciona (para curiosos y escépticos)  
2. **Convocar** al movimiento (para quienes quieren sumarse)  
3. **Proyectar** el futuro — las lands, la visión a largo plazo  
4. **Validar** que hay personas que quieren vivir en una land de Counity

Todo basado en hipótesis a validar con la primera comunidad real.

## A quién le hablamos (4 personas)

### Persona 1: **Nadia la Exploradora** (Curiosa / Busca sentido)

| Campo | Detalle |
| :---- | :---- |
| **Quién es** | 28-40 años. Profesional urbana (diseño, educación, tecnología, arte). Conectada digitalmente, desconectada existencialmente. |
| **Qué le pasa** | Siente que su trabajo no tiene impacto real. Consume contenido sobre sustentabilidad, comunidades, permacultura. Fantasea con "otra vida" pero no sabe por dónde empezar. |
| **Qué la frena** | Miedo a lo naif ("¿esto no es una utopía más?"). Necesita entender que puede participar desde donde está. |
| **Quote** | *"Quiero hacer algo que importe, pero no quiero unirme a una secta ni irme a vivir al monte."* |
| **CTA ideal** | "Conocé cómo se organiza Counity" → Lee más, se suscribe, empieza a orbitar. |
| **Hipótesis** | *\[H1\]* Hay un segmento urbano, profesional y frustrado que busca proyectos participativos con anclaje real. |

### Persona 2: **Lucas el Constructor** (Quiere sumarse / Tiene skill)

| Campo | Detalle |
| :---- | :---- |
| **Quién es** | 30-50 años. Facilitador, arquitecto, agrónomo, dev Web3, comunicador social. Ya tiene experiencia en proyectos colectivos. |
| **Qué le pasa** | Conoce la autogestión pero busca un proyecto con estructura, visión y gente seria. Cansado de iniciativas que empiezan y mueren. |
| **Qué lo frena** | Escepticismo. Necesita ver gobernanza real, no solo palabras. |
| **Quote** | *"He visto demasiados proyectos bonitos que mueren en el primer conflicto."* |
| **CTA ideal** | "Sumáte a una Co-Unit" → Formulario, sesión de bienvenida. |
| **Hipótesis** | *\[H2\]* Hay profesionales de impacto que buscan un ecosistema organizado donde su expertise tenga tracción. |

### Persona 3: **Sofía la Aliada** (Organizaciones / Alianzas)

| Campo | Detalle |
| :---- | :---- |
| **Quién es** | Directora de fundación, líder de cooperativa, investigadora. Piensa en sistemas. |
| **Qué le pasa** | Tiene recursos pero le falta un partner con visión sistémica. |
| **Qué la frena** | Necesita rigor. Si parece "startup crypto" o "comuna hippie", se va. |
| **Quote** | *"Buscamos aliados con visión real de gobernanza y regeneración, no marketing verde."* |
| **CTA ideal** | "Descargá nuestro Pink Paper" → Formulario de descarga. |
| **Hipótesis** | *\[H3\]* Hay organizaciones de impacto que serían aliadas si ven rigor estructural. |

### Persona 4: **María la Habitante** (Quiere vivir en una land)

| Campo | Detalle |
| :---- | :---- |
| **Quién es** | 30-55 años. Puede ser pareja con hijos, profesional independiente, jubilada activa. Viene de la ciudad pero sueña con una vida más conectada con la naturaleza y la comunidad. |
| **Dónde está** | Ciudades grandes de Latam y España. Probablemente ya probó vacaciones en el campo, retiros o volunteering. |
| **Qué le pasa** | Quiere salir de la ciudad pero no quiere irse sola al medio del campo. Busca un modelo donde pueda tener vivienda, comunidad, naturaleza y acceso a servicios. No quiere una ecoaldea aislada; quiere un modelo sostenible y con estructura. |
| **Qué la frena** | "¿Es real? ¿Cuándo podría mudarme? ¿Cuánto cuesta? ¿Cómo funciona la convivencia?". Necesita ver un plan tangible, no solo filosofía. |
| **Quote** | *"Me encantaría vivir en un lugar así, pero necesito saber que va en serio y que hay un plan real."* |
| **CTA ideal** | "Quiero vivir en una Counity Land" → Formulario específico de interés en habitar. |
| **Hipótesis** | *\[H6 — CRÍTICA\]* Hay personas que están dispuestas a vivir en una comunidad Counity si ven estructura, visión y un camino concreto para lograrlo. Esta es probablemente la hipótesis más importante del proyecto. |

## Parte 2: Narrative Arc del sitio

SCROLL DEL SITIO (historia que se cuenta al bajar)

1\. EL MUNDO CAMBIÓ (Tensión)

   "El modelo de habitar está roto"

2\. ALGO SE MUEVE (Esperanza)

   "Hay quienes ya están construyendo otra cosa"

3\. ESTO ES COUNITY (Identidad)

   "Counity: laboratorio vivo de comunidades que habitan el futuro"

   ↑ Frase con potencia — no divide, integra

4\. CÓMO FUNCIONA (Arquitectura)

   Nodos — Co-Units — Core (visual interactivo)

5\. LAS LANDS (Proyección / Futuro)

   Qué son, cómo serán, por qué importan

   → CTA: "Quiero vivir en una Counity Land"

6\. DÓNDE ESTAMOS HOY (Honestidad)

   Estado actual, lo que ya existe, lo que falta

7\. SUMATE (Convocatoria)

   Formas de participar \+ formularios

## Parte 4: Hipótesis a validar

| \# | Hipótesis | Métrica |
| :---- | :---- | :---- |
| H1 | Hay personas que resonan con la narrativa de "ruptura del habitar" | % visitantes que llegan al CTA / formulario |
| H2 | La estructura (gobernanza, Co-Units) genera confianza | Tiempo en sección "Cómo funciona" |
| H3 | La documentación profunda atrae aliados estratégicos | Descargas del Pink Paper \+ perfil |
| H4 | El tono invitacional genera más confianza que un pitch | Tasa de rebote \+ tiempo en sitio |
| H5 | El perfil "explorador urbano frustrado" es el más activo | Datos del formulario |
| **H6** | **Hay gente que quiere vivir en una Counity Land** | **Formularios de interés en habitar** |
